# 音画与抓取模式

本轮在用户确认 P2 运动手感后接入。参考 `desk-madeline` 固定提交
`8404a89e2a90cbafe35a97ef40f640083afd3c4c` 的 `GrabMode.cs`、
`Player.cs`、`PetWindow.cs`、`SoundEffects.cs` 和 `Particles.cs`；
Minecraft 静态方块、网络预测及渲染管线仍是本项目自身适配。

## 输入和设置

F8 的控制页顶部选择抓取模式：按住、反转、切换。后者在按下的下一子步
读取新锁存值；切换模式、离开世界或重新进入平面时重置锁存。用户原有多键
映射保存在同一个版本 1 JSON 中，新增 `grabMode`、`soundEnabled`、
`soundVolume`、`effectsEnabled` 都是可选字段，不改写旧键位。
音画页可独立关闭音效/特效，并调整音量。设置的 Celeste 目录同时用于图集
和 FMOD bank 查找。

## 资源和呈现

本地 Gameplay 图集解码玩家、汗滴、烟尘、斜线和 `util/glove`。Celeste
冲刺粒子原本是纯色矩形，运行时生成白色 1 像素纹理。角色有低体力闪红、
汗滴、待机 A/B/C 动作及对应偶发声音；跳跃、墙面、冲刺、落地有原版事件、
烟尘、冲刺尾迹和斜线。只在客户端首次预测调用表现回调，服务端及校正重放
继续执行相同物理算法但不产生音画事件。

声音从本机 Celeste 的 `Content/FMOD/Desktop` 读取原版 bank，调用兼容的
64 位 FMOD 1.x。缺少安装或运行库时只静音，设置页显示错误；不把商业资源
或 FMOD DLL 装入模组包。音效与 Minecraft 主音量/玩家音量共同生效。

## 验证边界

本地单元/集成测试覆盖抓取模式按键逐帧时序、旧配置默认值、待机与闪红、
手套和冻结帧、冲刺残影、图集汗滴帧与音效事件；无声 FMOD 输出模式验证
本机实际 bank 加载和事件查询。17 场景、2,905 帧的物理对照增加有/无表现
观察器的逐字段等价检查。

未启动 Minecraft；运行期音频设备、OpenGL 绘制、暂停/重载时序和多人
视觉效果仍需用户实机验收。效果覆盖玩家常见动作，不等同于 Celeste
所有关卡机制、死亡过场、动态实体与桌面版全套音画逐帧一致。
