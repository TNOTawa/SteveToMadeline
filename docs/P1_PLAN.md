# P1 二维基础开发顺序

依据：`初版开发计划书.txt` 第 2.1、2.2、3、4.2、4.4、5、6 节。
本文件记录实施顺序；用户已确认 P1 实机体验无问题并允许进入 P2，后续见 `P2_PLAN.md`。

## 用户追加规则（优先于初版计划）

- R **进入**和 Tab 转向时，将当前方块的水平 X/Z 吸附到 `floor(v) + 0.5`；Y 不改，
  避免把脚抬高、塞进地面或打断跳跃。R 退出只解除模式，不额外吸附或回到进入位置。
- 服务端先检查当前位置到中心的包围盒扫掠范围与世界边界，阻挡时原子取消，保留旧平面。
- 默认进入规则 `FACING_RIGHT`：进入前视线吸附到最近水平四方向后，成为屏幕右侧。
  可选择左侧、旧相机前向规则或固定南/西/北/东。
- Tab 逻辑平面确认后立即切换，摄像机沿玩家周围顺时针缓动 90°，默认 0.3 秒。
  新的横向输入暂缓，保留转换后的水平惯性和竖直速度；转动中最多缓存一次 Tab 请求。
- 实验 2.5D 只覆盖模式内视角，R 不再三态循环，始终进入/退出。

## 已确定的边界

- 用户接受当前 `DEPTH + ADAPTIVE` 画面，并要求作为默认。它取代初版计划的严格正交
  视觉基线；P1 不再重做投影、视差或建筑识别。旧方案只在实验选项中保留。
- R 仍是进入/退出开关，不因默认配置改变而在载入世界时自动进入。
- P1 先完成单人世界的基础行走、原版跳跃、平面约束和转向；Celeste 的 60Hz 物理、
  冲刺、墙跳、攀爬属于 P2，玛德琳和资源加载属于 P3，键位导入属于 P4。
- 公共状态不能依赖客户端图形类；专用服务端兼容边界要保留，但不在 P1 展开完整联机预测。

## 实施顺序

### 1. 四方向与平面状态

先建立 `core.mode` / `core.plane` 中的方向、轴映射、`PlaneState` 与生命周期。
统一表达 heading、锚点、屏幕水平轴、法线轴和 pendingTurn，为后续输入和物理提供接口。
进入时才从玩家视线吸附方向；进入后由状态持有方向，不能继续每帧从鼠标 yaw 重算。

方向、摄像机、实体切片、地形采样共享同一份状态。四向映射必须严格对应：
朝 ±Z 锁 Z、移动 XY；朝 ±X 锁 X、移动 ZY。

### 2. R 进入与无损退出

实现总开关、R 输入上下文、进入前条件检查和对称恢复。
进入时记录当前真实位置为锚点，只保存/接管必要的原版状态；退出时恢复相机和输入，
进入只做上述安全中心吸附，退出不重置位置、不新建玩家实体、不留下实验相机或模式状态。
先做可靠的进入/退出骨架，再往其中接移动与 Tab。

### 3. 平面输入、坐标约束与基础移动

将屏幕左右输入映射到平面水平轴，消除法线方向的输入和运动分量，保留原版重力、跳跃
以及三维 AABB 碰撞。不用每 tick 传送回锚点来掩盖错误的运动计算。
让客户端与内置服务端的模式/位置保持一致；必要时只增加最小模式状态同步，不提前实现 P6。

这一阶段交付：四个朝向下都能横向行走、正常跳跃、撞墙停下、退出回到原版移动。

### 4. Tab 顺时针转向与速度转换

以玩家当前所在方块的安全水平中心重建锚点，按南 → 西 → 北 → 东 → 南顺序切换法线。
同一更新周期内同步方向、输入映射、实体切片、地形采样和摄像机，避免视角先转而运动轴未转。
空中转向保留竖直速度，将屏幕横向速度转换到新轴；通过三维碰撞检查后再提交转向，
不合法时保留旧状态，不通过瞬移绕过碰撞。

Tab 只在模式启用且游戏内可操作时截获；原版模式的玩家列表、聊天和 GUI 行为保留。

### 5. 转向请求与 P2 接口

接入 `pendingTurn` 与“当前是否可安全转向”的入口，集中处理按键请求，避免散落在摄像机中。
P1 只实现基础移动状态的规则和可延期接口；冲刺、抓墙等不可中断状态的实际判定由 P2 接入，
不在 P1 伪造尚不存在的 Celeste 动作。

### 6. 生命周期收口与交付检查项

整理死亡/重生、传送、维度变化、退出世界、配置关闭时的清理或锚点重建，
不能拿旧锚点把玩家拉回原位置。补充回归测试源码与用户实机检查清单：

- R 进入只改变 X/Z 到安全中心，Y 不变；退出不改变位置并恢复原版控制。
- 在静止方块中心连续 Tab 四次回到原朝向，没有累计坐标漂移；移动中每次重新居中。
- 四方向的屏幕左右始终一致；移动鼠标不会偷偷改变运动平面。
- 跳跃/落地下转向不丢失竖直速度，不穿过方块。
- GUI/聊天不误触发；退出/换维度后没有残留锁轴或相机。

按用户约定，编译与打包可由代理执行，测试与游戏体验由用户进行。

## 完成定义

闭环是：**R 进入 → 横向行走/跳跃 → Tab 原地换平面 → 继续移动 → R 无损退出**。
闭环完成后进入 P2，不再把 P0 视觉实验扩展为 P1 的前置任务。
